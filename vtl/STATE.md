## 四、已知坑（都会让数字变假）

1. **同进程重复合成不完全可复现**：谱差中位 0.39 dB → 这是目标函数噪声底，残差不可能低于它。
2. **首帧必须 0 采样**，否则初始化不对。
3. `addTube`（面积函数路径）当前输出 NaN，未修。
4. 旧 API 没有 `vtlSynthesisReset`，状态无法完全复位。
5. 归一化只允许在 `feats.py` 里做一处；`invariants.py` 会扫重复实现。

## 五、关键实测（v2 口径，持续声）

| 测试 | 结果 | 判定 |
|---|---|---|
| 闭环自检（同参数反推） | 残差 **0.56 dB**，参数误差 6% | 工具可信（噪声底 0.39） |
| 可辨识性（6 组随机真值） | 残差中位 **0.66 dB**（0.27–3.45）；参数 MAE 中位 **19.6%**（4.8–37.5%） | **频谱可拟合，形状不唯一** |
| 模糊维度 | JA 最差 77.9% / 69% / 56.8%；LD 77.9% / 24.6% | TCX/TCY 稳，JA/LD 互相补偿 |
| 低音高特例 | f0=110 时残差 3.45 dB | 谐波少 → 频谱信息不足 |

结论：**"参数不可辨识"在修好合成后依然成立**，不是衰减声的假象。
因此：参数 MSE 不能当损失；必须用频谱损失 + 多候选择优。
